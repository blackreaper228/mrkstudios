# mrkstudios

Портфолио с интерактивным 3D-телевизором и каруселью из пяти видео. После входа через телевизор открывается белая страница с локальным временем, логотипом mrk, объёмным наклоном видео и курсором Play. Боковые области, стрелки клавиатуры и свайпы переключают ролики. Нажатие на видео открывает просмотр со звуком.

## Локальный просмотр

Запустите из папки dist:

```sh
python -m http.server 4173
```

Откройте http://127.0.0.1:4173/ . Сборка и установка зависимостей не требуются.

## Файлы

- dist/index.html — разметка страницы и ссылка contact.
- dist/style.css — оформление, Inter и Instrument Serif.
- dist/app.js — 3D-телевизор и переход к портфолио.
- dist/carousel.js — пять роликов, названия, карусель, тильт и курсор.
- docs — копия сайта для GitHub Pages (main /docs). После изменений dist нужно обновить эту копию.

Сайт: https://blackreaper228.github.io/mrkstudios/

Ролики — временные внешние демонстрационные материалы W3Schools, W3C и MDN. Замените массив films в carousel.js на работы клиента перед финальным использованием. Three.js загружается с jsDelivr, шрифты — с Google Fonts. Для contact пока указан mailto: без получателя; адрес клиента ещё не задан. Menu намеренно статичен.
