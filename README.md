# mrkstudios

Черновик сайта-портфолио с интерактивным 3D-телевизором. Телевизор реагирует на курсор, а по нажатию приближает экран и открывает галерею.

## Локальный просмотр

Запустите любой статический сервер из папки `dist` и откройте его адрес в браузере. Например:

```sh
cd dist
python -m http.server 4173
```

Сборка и установка зависимостей не требуются. Модель работает на Three.js, библиотека загружается через jsDelivr.

Изображения в галерее загружаются с Picsum и служат временными заглушками. Перед передачей сайта клиенту замените их на фотографии его работ и обновите подписи.
